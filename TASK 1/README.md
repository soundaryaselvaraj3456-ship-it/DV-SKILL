# TASK-1-Superstore Sales Data Understanding, Cleaning & Exploratory Data Analysis (EDA)

## Project Description

This project demonstrates **Data Understanding, Data Cleaning, and Exploratory Data Analysis (EDA)** using the **Superstore Sales** dataset in Python. The analysis helps identify sales trends, profit distribution, and category-wise performance through statistical analysis and visualizations.

---

## Features

- Load the Superstore Sales dataset
- Display dataset information
- Check for missing values
- Remove duplicate records
- Calculate average sales
- Perform statistical analysis
- Generate visualizations:
  - Sales Distribution (Histogram)
  - Sales by Category (Bar Chart)
  - Sales vs Profit (Scatter Plot)
- Split the dataset into training and testing sets

---

## Technologies Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn
